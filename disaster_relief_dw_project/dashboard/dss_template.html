Ranks districts by relief priority using four warehouse-derived factors: impact severity, aid coverage gap, shelter overcrowding risk, and baseline vulnerability. Adjust the weights below to see how the ranking responds — this is a transparent, rule-based score, not a black box.

Priority Weights

Priority Score = (Impact × w₁) + (Aid Gap × w₂) + (Shelter Risk × w₃) + (Vulnerability × w₄), each factor normalized 0–1 across districts (shelter risk can exceed 1.0 when occupancy exceeds capacity). Recomputed live in your browser as you move the sliders — no server round-trip.
